## Задача: повторно проверить новые редакции требований

Тебе дан исходный документ и новые редакции некоторых требований, написанные после ответа автора. Проверь каждую новую редакцию по свойствам ISO/IEC/IEEE 29148:2018, п. 5.2.5, с учётом остального документа.

### Свойства

$criteria

- Верни запись для каждого `rid`. Если новая редакция хорошая, оставь `findings` пустым.
- Сообщай только о дефектах, которые остались или появились в новой редакции. Не повторяй замечания, которые редакция уже закрыла.
