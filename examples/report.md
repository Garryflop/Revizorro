**Нарушения (1)**

1. **F-003 · Проверяемость · критично.** Тест «Маршрутизация приложения и покупки по архитектурным связям» нельзя довести до ожидаемого результата
   - Где: «Мобильное приложение → сервис настроек. Карточный процессинг → учёт расходов → сервис push.» — Часть A. Новый функционал › Архитектура решения, строка 26
   - Проблема: Указаны только направления связей; не определены операции между приложением и сервисом настроек, контракты и критерии успешного обмена. Дочерний REST API описывает сохранение, но одновременно указывает GET и упоминает чтение только в Description, не задавая отдельного контракта чтения.
   - Последствия: Тестировщик не сможет определить ожидаемый результат; допустимы варианты: Текст задаёт направления связей: мобильное приложение → сервис настроек; карточный процессинг → учёт расходов → сервис push. Конкретные операции, контракты сообщений и ожидаемое поведение при сбое связи не определены.
   - Как исправить: Указать для каждой связи инициатора, операцию, контракт запроса и ответа, а также ожидаемое поведение при недоступности компонента. Согласовать метод и операции REST API, отдельно описав чтение и сохранение настроек.

## Приложение A. Как проводилась проверка

1. **Загрузка.** Документ (markdown) разобран на 124 блоков с якорями: раздел, строка. Линтер на правилах нашёл 25 сигналов (размытые слова, заглушки, пустые разделы, смешение единиц) — они переданы агентам как подсказки.
2. **Нарезка.** Агент-нарезчик выделил требования; код проверил якоря и цитаты и перенумеровал требования по порядку. Блоки, которые остались без классификации, прошли второй проход нарезки.
3. **Параллельная проверка.** Ревьюер требований (ISO 29148 п. 5.2.5), тест-дизайнер, ревьюер согласованности и ревьюер полноты (ISO 29148 п. 5.2.6, IEEE 830 п. 4.3), а также ревьюер контракта API работали одновременно.
4. **Верификация.** Код сверил каждую цитату с текстом документа; агент-критик перепроверил каждую находку, отклонил ложные и объединил дубли.
5. **Вопросы и итог.** Агент уточнений составил вопросы-развилки, агент-итог — вердикт. Все числа в сводке посчитаны кодом.

Воронка находок: всего 112 → цитата подтверждена у 112 → отклонено критиком 10, объединено дублей 48 → в отчёте **54**.
